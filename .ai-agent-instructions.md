# AI Agent Instructions for Publishing to GitHub

When the user asks you to "upload to GitHub" or "publish", ALWAYS perform the following steps:

1.  **Check for New Files**: Check if any new simulator files (e.g., `*.html`) were added to the `tools/` directory.
2.  **Update `index.html`**: If a new tool was added, create a new card entry for it in the main grid of `index.html`.
3.  **Update `README.md`**: If a new tool was added, add its description and file path to both the English and Traditional Chinese sections of `README.md` (in the Tools list and the Project Structure list).
4.  **Git Operations**:
    *   `git add .`
    *   `git commit -m "Your descriptive commit message here"`
    *   `git push`

This ensures that the live GitHub Pages site and documentation are always up to date with the latest code changes.
